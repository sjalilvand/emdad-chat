## روش سریع (PowerShell) — پیشنهادی

روی سرور ویندوز، یک بار این دستور را در PowerShell (با دسترسی Administrator) اجرا کنید؛
همه گام‌های زیر (دریافت کد از گیت‌هاب، نصب، دیتابیس، ساخت، فایروال و اجرا) خودکار انجام می‌شود:

```powershell
powershell -ExecutionPolicy Bypass -File deploy\setup-server.ps1
```

- اجرای دوباره همین اسکریپت = به‌روزرسانی کد از گیت‌هاب + ساخت و اجرای مجدد.
- توقف سرویس: `deploy\stop-server.ps1` — اجرای مجدد بدون build: `deploy\start-server.ps1`
- اجرای در پیش‌زمینه با لاگ زنده: `deploy\setup-server.ps1 -Foreground`

بارگذاری تغییرات کد در گیت‌هاب (از هر دستگاهی):

```powershell
$env:GITHUB_TOKEN = "توکن-دسترسی"
powershell -ExecutionPolicy Bypass -File scripts\push-to-github.ps1 -Message "شرح تغییرات"
```

> توکن توصیه می‌شود فقط در متغیر محیطی نگه‌داری شود و در فایل‌ها ذخیره نشود.

## گام ۰ — پیش‌نیازها روی سرور

1. **Ollama** نصب و مدل‌ها دانلود شده باشند (خودتان انجام داده‌اید):
   - `qwen3:8b` ، `qwen3:4b` ، `qwen2.5vl:3b`
2. **Node.js نسخه ۲۰ یا بالاتر** — از https://nodejs.org نصب کنید.
   - بررسی: `node -v`
3. اگر فایروال دارید، پورت **8094** را باز کنید.

> **نکته Ollama:** اگر اپلیکیشن و Ollama روی **همان سرور** هستند، پیش‌فرض `http://127.0.0.1:11434` درست است.
> حتماً از `127.0.0.1` استفاده کنید نه `localhost`؛ چون Node.js ممکن است `localhost` را به IPv6 (::1) حل کند در حالی که Ollama ویندوز فقط روی IPv4 گوش می‌دهد و خطای «اتصال برقرار نشد» می‌بینید.
> اگر Ollama روی دستگاه دیگری است، در آن دستگاه متغیر `OLLAMA_HOST=0.0.0.0` را تنظیم کنید تا از شبکه قابل دسترسی باشد و در فایل `.env` این پروژه آدرس `http://IP-دستگاه:11434` را بنویسید.

## گام ۱ — کپی پروژه روی سرور

کل پوشه پروژه (شامل پوشه‌های `data` و `db` و `prisma` و `src`) را روی سرور کپی کنید، مثلاً:

- ویندوز: `C:\emdad-chat`
- لینوکس: `/opt/emdad-chat`

## گام ۲ — ساخت فایل .env

از فایل `deploy/.env.example` یک کپی به نام `.env` در ریشه پروژه بسازید و مسیر دیتابیس را مطلق کنید:

```
# ویندوز (نمونه)
DATABASE_URL=file:C:/emdad-chat/db/custom.db
```
> حتماً مطمئن شوید `MOCK_LLM` در `.env` وجود **نداشته** باشد یا برابر false باشد؛ این متغیر فقط برای تست بدون Ollama است.

## گام ۳ — اجرا

### روش الف) ویندوز (ساده‌ترین)

روی فایل `deploy\start-windows.bat` دوبار کلیک کنید. همه مراحل (نصب، دیتابیس، ساخت، اجرا) خودکار است. پنجره باز بماند تا سرویس فعال باشد.

### روش ب) لینوکس

```bash
bash deploy/start-linux.sh
```

### روش ج) اجرای دائمی با PM2 (پیشنهادی برای سرور)

```bash
npm install -g pm2
pm2 start deploy/ecosystem.config.cjs
pm2 save
pm2 startup    # اجرای خودکار پس از ری‌استارت سرور
```

مدیریت: `pm2 status` ، `pm2 logs emdad-chat` ، `pm2 restart emdad-chat`

## عیب‌یابی

| مشکل | راه‌حل |
|------|--------|
| «اتصال به Ollama برقرار نیست» | `ollama serve` یا سرویس Ollama را اجرا کنید؛ آدرس `OLLAMA_BASE_URL` را چک کنید |
| نقطه قرمز ولی Ollama در حال اجراست | اگر اپ روی دستگاه دیگری است، `OLLAMA_HOST=0.0.0.0` را در دستگاه Ollama تنظیم کنید |
| پاسخ صفحات امداد قدیمی/خالی است | دکمه به‌روزرسانی پایگاه دانش (🔄) را بزنید؛ دسترسی سرور به komiteemdad.emdad.ir را چک کنید |
| جستجوی اینترنت بی‌نتیجه است | موتورهای Bing و DuckDuckGo امتحان می‌شوند؛ در برخی شبکه‌ها فیلتر است. می‌توانید سرور SearXNG خودتان را با متغیر `SEARXNG_URL` معرفی کنید |
| پورت بسته است | ویندوز: `netsh advfirewall firewall add rule name="EmdadChat8094" dir=in action=allow protocol=TCP localport=8094` |
| خطای دیتابیس | مقدار `DATABASE_URL` در `.env` باید مسیر مطلق و قابل‌نوشتن باشد؛ سپس `npx prisma db push` |

## ساختار فنی (خلاصه)

- **فریم‌ورک:** Next.js 16 + TypeScript + Tailwind + shadcn/ui (RTL)
- **دیتابیس:** SQLite با Prisma (گفتگوها، پیام‌ها، کش صفحات امداد)
- **مدل:** Ollama API با استریم SSE؛ تفکر از `message.thinking` یا تگ‌های `<think>` استخراج می‌شود
- **پایگاه دانش:** قطعه‌بندی اسناد + جستجوی واژگانی فارسی (نرمال‌سازی ی/ک عربی، حذف اعراب، stemming سبک) و تزریق بهترین قطعات به زمینه مدل
- **جستجوی وب:** زنجیره Bing HTML → Bing RSS → Bing News RSS → DDG → Google → SearXNG با فیلتر ارتباط
